# MASTER PROMPT — WEBSITE TRYOUT UPKP IMIPAS

Saya ingin membangun website **Tryout UPKP** berbayar untuk persiapan ujian, dengan fokus awal pada **UPKP Kementerian Imigrasi dan Pemasyarakatan (Imipas)**.

Bangun aplikasi ini sebagai aplikasi production-ready sederhana, ringan, mudah dipelihara, dan murah dijalankan.

## 1. STACK WAJIB

Gunakan:

* Backend: **Hono**
* Runtime: **Cloudflare Workers**
* Database: **Cloudflare D1**
* Frontend: HTML + CSS + Vanilla JavaScript
* Jangan gunakan React/Vue/Next.js kecuali benar-benar diperlukan.
* Jangan gunakan ORM berat.
* Gunakan SQL langsung untuk D1.
* Authentication menggunakan session berbasis cookie.
* Password disimpan menggunakan algoritma hashing yang aman dan ringan. Prioritaskan **Argon2id** jika kompatibel dengan environment; jika tidak praktis di Cloudflare Workers, gunakan library bcrypt yang kompatibel.
* Payment gateway: **Pakasir**
* Deployment: Cloudflare Workers
* Configuration/secrets menggunakan Cloudflare secrets / `.dev.vars`.
* Jangan menyimpan API key Pakasir di source code.

Tujuan utama: aplikasi ringan, cepat, sederhana, dan mudah dikembangkan.

# 30. PAYMENT PAKASIR

Integrasikan Pakasir.

Credential:

```env
PAKASIR_API_KEY=
PAKASIR_PROJECT=
```

Jangan commit credential.

Flow:

```text
User pilih produk
↓
Server membuat transaksi
↓
Pakasir payment
↓
User membayar
↓
Pakasir callback/webhook
↓
Server memvalidasi transaksi
↓
Payment = PAID
↓
access_expires_at diperbarui
```

Pastikan webhook idempotent.

Jika callback diterima dua kali, jangan menggandakan masa akses.

Jika user masih memiliki akses:

```text
tanggal_expired_lama + durasi_produk
```

Jika sudah expired:

```text
tanggal_sekarang + durasi_produk
```

Contoh:

Akses sampai 1 Oktober.

Membeli 7 hari pada 25 September:

→ menjadi 8 Oktober.

Jika akses sudah habis:

→ mulai dari waktu pembayaran sukses.

Gunakan waktu UTC di database dan konversi ke WITA pada UI bila diperlukan.

# 46. ADMIN EDIT SOAL

Jika soal sudah digunakan pada attempt:
